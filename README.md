# AutoGestor-Market (English)

Automated system to process purchase receipts using Google Drive, Google Sheets, and the Gemini API (Vision and Text). 

For security reasons, credentials, tokens, and environment configurations are not included in this repository. To run the project locally, you must configure your own Google Cloud and Gemini environment by following the steps below.

## 1. Installation and Setup

Clone the repository and install the necessary dependencies:

```bash
git clone https://github.com/your-username/AutoGestor-Market.git
cd AutoGestor-Market
pip install -r requirements.txt
```

You must manually create the following items in the root directory of the project:
* A `settings.json` file
* A `credentials/` folder
* A `json_temp/` folder (empty, for temporary processing)

## 2. Obtain Google Cloud Credentials (`client_secrets.json`)

This file allows the code to interact with your personal Google Drive and Google Sheets accounts.

1. Go to the [Google Cloud Console](https://console.cloud.google.com/).
2. Create a new project.
3. Navigate to **APIs & Services > Library** and enable two APIs for your project:
   * **Google Drive API**
   * **Google Sheets API**
4. Go to **APIs & Services > OAuth consent screen** and configure it as "External". Add your email address in the "Test users" section.
5. Go to **Credentials > Create Credentials > OAuth client ID**.
6. Select the application type as **Desktop app**.
7. Download the JSON file generated at the end.
8. Rename that downloaded file to exactly `client_secrets.json` and move it inside the `credentials/` folder of your project.

## 3. Configure `settings.json`

Create a file named `settings.json` in the root of the project. This file acts as the system's map. Copy the following structure and insert your corresponding data:

```json
{
  "rutas": {
    "credenciales": "credentials/client_secrets.json",
    "json_temp": "json_temp"
  },
  "google_drive_links": {
    "fotos_pendientes": "PENDING_FOLDER_LINK_OR_ID",
    "fotos_procesados": "PROCESSED_FOLDER_LINK_OR_ID"
  },
  "google_sheets": {
    "spreadsheet_id": "YOUR_GOOGLE_SHEET_LINK_OR_ID",
    "hoja_principal": "MERCADO MENSUAL",
    "hoja_historico": "HISTORIAL COMPRAS"
  },
  "ia_config": {
    "gemini_api_key": "YOUR_GEMINI_API_KEY",
    "vision": {
      "primario": "gemini-3.1-flash-lite",
      "respaldos": ["gemini-2.5-flash", "gemini-1.5-flash-latest"]
    },
    "texto": {
      "primario": "gemma-4-31b",
      "respaldos": ["gemma-3-27b", "gemini-3.1-flash-lite", "gemini-2.5-flash", "gemini-1.5-flash-latest"]
    }
  }
}
```

**How to get this data?**
* **Google Drive Links:** Go to your Google Drive, create two folders (one where you will upload the receipt photos and another where the system will archive them). Copy the full link (URL) of each folder and paste it into its respective field.
* **Google Sheets:** Create a new file in Google Sheets, make sure to create a tab named `HISTORIAL COMPRAS`, and paste the full URL of the document into `spreadsheet_id`.
* **Gemini API Key:** Go to [Google AI Studio](https://aistudio.google.com/app/apikey), generate a new API Key, and copy it into the `gemini_api_key` field.

## 4. Generate `token.json`

**Do not create this file manually.** The `token.json` file is automatically generated by the code the first time it starts, and it serves to keep your session open without asking for permissions every day.

To generate it:
1. Ensure your `client_secrets.json` is in place and your `settings.json` is correctly filled out.
2. Run the main script from your terminal:
   ```bash
   python main.py
   ```
3. A tab will automatically open in your web browser asking you to sign in with Google.
4. Select the email account where you created your folders and Excel sheet, and grant the requested permissions for Drive and Sheets. *(Note: If a "Google hasn't verified this app" warning appears, click on "Advanced" and then "Go to [Your App Name] (unsafe)" to continue).*
5. Once accepted in the browser, return to your code editor. You will see that the `token.json` file has automatically appeared in the root of the project.

## 5. System Execution

With all the configuration ready, the system is operational. To process information, simply upload images (JPG, PNG, PDF, HEIC) to your assigned "pending photos" Drive folder and run in your terminal:

```bash
python main.py
```

# AutoGestor-Market (Español)

Sistema automatizado para procesar tickets de compra utilizando Google Drive, Google Sheets y la API de Gemini (Visión y Texto). 

Por razones de seguridad, las credenciales, tokens y configuraciones de entorno no están incluidas en este repositorio. Para ejecutar el proyecto localmente, debes configurar tu propio entorno de Google Cloud y Gemini siguiendo los pasos a continuación.

## 1. Instalación y Preparación

Clona el repositorio e instala las dependencias necesarias:

```bash
git clone https://github.com/tu-usuario/AutoGestor-Market.git
cd AutoGestor-Market
pip install -r requirements.txt
```

Deberás crear manualmente los siguientes elementos en el directorio raíz del proyecto:
* Un archivo `settings.json`
* Una carpeta `credentials/`
* Una carpeta `json_temp/` (vacía, para el procesamiento temporal)

## 2. Obtener Credenciales de Google Cloud (`client_secrets.json`)

Este archivo permite que el código interactúe con tus cuentas personales de Google Drive y Google Sheets.

1. Ve a la [Consola de Google Cloud](https://console.cloud.google.com/).
2. Crea un proyecto nuevo.
3. Navega a **APIs y Servicios > Biblioteca** y habilita dos APIs para tu proyecto:
   * **Google Drive API**
   * **Google Sheets API**
4. Ve a **APIs y Servicios > Pantalla de consentimiento de OAuth** y configúrala como "Externa". Añade tu correo electrónico en la sección de "Usuarios de prueba".
5. Ve a **Credenciales > Crear Credenciales > ID de cliente de OAuth**.
6. Selecciona el tipo de aplicación como **App de escritorio**.
7. Descarga el archivo JSON que se genera al finalizar.
8. Renombra ese archivo descargado exactamente a `client_secrets.json` y muévelo dentro de la carpeta `credentials/` de tu proyecto.

## 3. Configurar `settings.json`

Crea un archivo llamado `settings.json` en la raíz del proyecto. Este archivo actúa como el mapa del sistema. Copia la siguiente estructura e inserta tus datos correspondientes (puedes referenciarte en el bloque JSON de la versión en inglés de arriba).

**¿Cómo obtener estos datos?**
* **Google Drive Links:** Ve a tu Google Drive, crea dos carpetas (una donde subirás las fotos de los tickets y otra donde el sistema las archivará). Copia el enlace completo (URL) de cada carpeta y pégalo en su campo respectivo.
* **Google Sheets:** Crea un archivo nuevo en Google Sheets, asegúrate de crear una pestaña llamada `HISTORIAL COMPRAS` y pega la URL completa del documento en `spreadsheet_id`.
* **Gemini API Key:** Ve a [Google AI Studio](https://aistudio.google.com/app/apikey), genera una nueva clave de API (API Key) y cópiala en el campo `gemini_api_key`.

## 4. Generar el `token.json`

**No debes crear este archivo manualmente.** El archivo `token.json` es generado de forma automática por el código la primera vez que inicia, y sirve para mantener tu sesión abierta sin pedirte permisos todos los días.

Para generarlo:
1. Asegúrate de tener en su lugar el `client_secrets.json` y el `settings.json` llenos correctamente.
2. Ejecuta el script principal desde tu terminal:
   ```bash
   python main.py
   ```
3. Se abrirá automáticamente una pestaña en tu navegador web pidiéndote iniciar sesión con Google.
4. Selecciona el correo electrónico donde creaste tus carpetas y tu Excel, y otorga los permisos solicitados para Drive y Sheets. *(Nota: Si aparece una advertencia de "Google no ha verificado esta app", haz clic en "Configuración Avanzada" y luego en "Ir a [Nombre de tu app] (no seguro)" para continuar).*
5. Una vez aceptes en el navegador, vuelve a tu editor de código. Verás que el archivo `token.json` ha aparecido en la raíz del proyecto de forma automática.

## 5. Ejecución del Sistema

Con toda la configuración lista, el sistema está operativo. Para procesar información, simplemente sube imágenes (JPG, PNG, PDF, HEIC) a tu carpeta de Drive asignada para "fotos pendientes" y ejecuta en tu terminal:

```bash
python main.py
```
